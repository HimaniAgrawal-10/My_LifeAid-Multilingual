
# 🩺 LifeAid — Multilingual Emergency Assistance

**Emergency help, in a language you understand.**

LifeAid is a web-based emergency assistance application designed to help users access first-aid guidance, locate nearby hospitals, find blood donors, and reach emergency contacts.

<p align="center">
  <strong>🌐 Multilingual • 🚑 Emergency Support • 🏥 Hospital Finder • 🩸 Blood Donor Search</strong>
</p>

---

## ✨ Features

| Feature | Description |
|---|---|
| 🌐 **Multilingual Support** | Select a preferred language during login and view supported emergency guidance in that language. |
| ❤️ **First-Aid Guides** | Emergency guidance for heart attacks, burns, snake bites, bleeding, and choking. |
| 📍 **Nearby Hospital Finder** | Uses browser location to search for nearby hospitals and display results on a map. |
| 🩸 **Blood Donor Finder** | Register as a donor and search for donors. |
| 🏥 **Hospital Directory** | Add and search hospital information. |
| 📞 **Emergency Contacts** | Access emergency contact information. |

## 🛠️ Built With

- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Maps:** Leaflet, OpenStreetMap

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/HimaniAgrawal-10/My_LifeAid-Multilingual.git
cd My_LifeAid-Multilingual
```

### 2. Open the application folder

If `app.py` is inside a subfolder, navigate into that folder before continuing.

### 3. Install dependencies

If the project contains `requirements.txt`:

```bash
python -m pip install -r requirements.txt
```

If it does not, install Flask:

```bash
python -m pip install flask
```

Install any additional packages if your application reports that they are missing.

### 4. Run LifeAid

```bash
python app.py
```

Open the local URL shown in your terminal. It is usually:

```text
http://127.0.0.1:5000
```

## 📍 Using the Nearby Hospital Finder

1. Open **Nearby Hospitals** in LifeAid.
2. Allow location access in your browser.
3. Choose a search radius.
4. View the hospitals found around your location on the map.

Hospital results depend on available map data and may not include every hospital. Verify hospital details directly when possible.
